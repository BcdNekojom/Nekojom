วิธีเพิ่มเพลงพื้นหลัง
======================

1. นำไฟล์เพลง .mp3 มาวางไว้ในโฟลเดอร์ music/ นี้
   เช่น music/track1.mp3, music/track2.mp3, music/track3.mp3

2. เปิดไฟล์ index.html ด้วยโปรแกรมแก้ไขข้อความ
   หาส่วนนี้ในโค้ด (อยู่ใกล้ท้ายไฟล์):

   const tracks = [
     { title: "เพลงพื้นหลัง 1", src: "music/track1.mp3" },
     { title: "เพลงพื้นหลัง 2", src: "music/track2.mp3" },
     { title: "เพลงพื้นหลัง 3", src: "music/track3.mp3" }
   ];

3. แก้ "title" เป็นชื่อเพลงจริงที่จะให้แสดงบนเว็บ
   แก้ "src" ให้ตรงกับชื่อไฟล์ mp3 ที่คุณวางไว้ในโฟลเดอร์นี้

4. อยากเพิ่มเพลงมากกว่า 3 เพลง ก็เพิ่มบรรทัดแบบเดิมต่อได้เลย เช่น
   { title: "เพลงพื้นหลัง 4", src: "music/track4.mp3" }

หมายเหตุ: ต้องอัปโหลดทั้งโฟลเดอร์ (index.html, music/, video/) ขึ้นไปพร้อมกัน
มิฉะนั้นเพลงและวิดีโอจะไม่เล่น เพราะพาธไฟล์อ้างอิงกันอยู่
